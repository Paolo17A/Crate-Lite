# Tailwind class guide

Reference of every Tailwind-related class used in Crate Lite. Classes are listed alphabetically.

Theme tokens come from `@theme inline` in [`app/globals.css`](app/globals.css). Custom classes are plain CSS in that same file.

## Source legend

| Source | Meaning |
|--------|---------|
| **Tailwind** | Built-in Tailwind CSS utility (including arbitrary-value syntax like `w-[…]`, `bg-[#…]`). |
| **Theme** | Utility auto-generated from our `@theme inline` tokens (brand colors / fonts). |
| **Custom** | Hand-written CSS class in `globals.css` (not generated by Tailwind). |
| **Tailwind + Custom** | Tailwind arbitrary utility that references a custom `@keyframes` (or similar) we defined. |

### Theme tokens (`@theme inline`)

| Token | CSS variable | Value / role |
|-------|--------------|--------------|
| `espresso` | `--color-espresso` | `#2b2623` — primary text / dark surfaces |
| `sand` | `--color-sand` | `#f4efe6` — light panels / light text on dark |
| `parchment` | `--color-parchment` | `#e6d7c3` — page background |
| `burnt-orange` | `--color-burnt-orange` | `#c76b3c` — accent / CTAs |
| `stone` | `--color-stone` | `#c8c2b8` — borders (overrides default Tailwind stone) |
| `brand` | `--font-brand` | Proxima Nova stack (logo wordmark) |
| `headline` | `--font-headline` | Playfair Display stack |
| `performer` | `--font-performer` | Helvetica Neue stack (UI body) |
